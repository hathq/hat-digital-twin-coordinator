# Digital Twin Coordinator HAT

An explicitly installed HAT for reviewing composition, priorities, and connection readiness. Consumers invoke its signed package and worker through the declared HAT interface.

Installation and activation require explicit authorization. Proposed HAT changes, identity decisions, and effects remain subject to their owning authorization boundaries. `information-link-check` produces an explicit diagnostic Situation for reviewing a data path. It does not infer a current location or fill in identity data.
